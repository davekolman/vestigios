# Dave Kolman — Vestigios / Cápsula 2026

Landing page editorial lista para GitHub Pages.

## Publicar
1. Crea un repositorio en GitHub.
2. Sube `index.html`, `style.css`, y las carpetas `images` y `video`.
3. En Settings → Pages, selecciona Deploy from a branch → `main` → `/ (root)`.

## Personalizar
- Reemplaza los bloques `IMAGEN...` por tus fotos.
- Coloca el vídeo promocional en `video/vestigios.mp4` y descomenta el bloque `<video>` de `index.html`.
- Cambia los nombres de las piezas, textos, Instagram y correo.
